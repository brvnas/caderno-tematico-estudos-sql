# Prompts Utilizados na IA

## Prompt 1: Conceitos básicos.

**Pergunta:**
"Explique o que é SQL para uma pessoa que está começando a estudar."

**Resultado:**
A IA explicou que SQL é uma linguagem utilizada para trabalhar
com bancos de dados relacionais.

**Dificuldade:**
A primeira resposta utilizou termos muito técnicos.

**Alteração/Melhoria do Prompt:**
"Explique o que é SQL para um iniciante, usando exemplos simples."

## Prompt 2: Corrigindo código.

**Pergunta:**
"Analise este código SQL e identifique possíveis erros:"
>
> SELECT nome idade FROM usuarios;

**Resultado:**
A IA identificou que faltava uma vírgula entre `nome` e `idade`.

**Melhoria:**
Passei a pedir para a IA explicar o erro e mostrar a versão corrigida para maior clareza nos estudos.

## Prompt 3: Tirando dúvidas.

**Pergunta:**
"Qual é a diferença entre SELECT, WHERE e ORDER BY? Explique de forma simples e dê exemplos."

**Resultado:**
A IA explicou a função de cada comando e apresentou exemplos práticos. Gostei da resposta e resolvi não alterar o prompt.
