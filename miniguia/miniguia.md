# Miniguia de Estudo sobre SQL

## O que é SQL?

SQL (Structured Query Language) é uma linguagem utilizada
para consultar, inserir, alterar, excluir e manipular dados em bancos de dados relacionais.

## Principais comandos

### SELECT
Usado para consultar dados.

### INSERT
Usado para inserir novos dados.

### UPDATE
Usado para alterar dados existentes.

### DELETE
Usado para excluir dados.

### WHERE
Usado para definir condições em uma consulta.

### ORDER BY
Usado para ordenar os resultados.

## Exemplo

SELECT nome, idade
FROM usuarios
WHERE idade > 18;

## Glossário

**SQL:** linguagem utilizada para trabalhar com bancos de dados.

**Banco de dados:** sistema utilizado para armazenar e organizar dados.

**Tabela:** estrutura formada por linhas e colunas.

**SELECT:** comando utilizado para consultar dados.

**INSERT:** comando utilizado para inserir dados.

**UPDATE:** comando utilizado para atualizar dados.

**DELETE:** comando utilizado para excluir dados.

**WHERE:** define uma condição para a consulta.

**FROM:** indica de qual tabela os dados serão buscados.
