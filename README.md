# Caderno Temático de SQL - Bootcamp Power BI

## Contexto e Objetivos

Este caderno temático é um projeto do bootcamp de Power BI do Santander/Plataforma DIO e tem como assunto de interesse a **SQL (Structured Query Language)**, uma linguagem utilizada para consultar, inserir, alterar e organizar dados em bancos de dados relacionais. O principal objetivo deste material é **estudar e aprender SQL**, desenvolvendo conhecimentos que permitam compreender a linguagem e utilizá-la corretamente na prática. Ao longo dos estudos, o caderno também será utilizado para registrar conteúdos, exemplos e exercícios que ajudem na fixação do aprendizado, além de ser usado como ferramenta de apoio durante os estudos, principalmente para **tirar dúvidas, compreender conceitos, buscar explicações sobre comandos e identificar possíveis erros no código**.
